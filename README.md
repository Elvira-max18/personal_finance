# Личный финансовый учёт

Главное меню (до входа):
1. Вход
2. Регистрация
3. Выход

Главное меню (после входа):
1. Мои операции (добавить/удалить/изменить)
2. Управление категориями
3. Управление счетами
4. Управление метками (тегами)
5. Бюджет
6. Отчёты
7. Выйти из аккаунта

Меню операций:
1. Добавить операцию
2. Редактировать операцию
3. Удалить операцию
4. Показать все операции (с фильтрами)
5. Назад

## Технологии
- Python 3.9+
- MySQL 8.0+
- Консольный интерфейс
